│  │              │         │              │         │

│  │ • 零延迟     │         │ • 可靠性高   │         │

### 2. 智能降级逻辑

```
if lastKline.IsZero() || time.Since(lastKline) > triggerPeriod + 1分钟 {
    // 触发降级
}

解释:
┌─────────────────────────────────────────────┐
│ lastKline.IsZero()                          │
│ • WebSocket 从未触发过                      │
│ • 启动失败或配置错误                        │
│ → 立即使用定时器                            │
├─────────────────────────────────────────────┤
│ time.Since(lastKline) > triggerPeriod + 1m  │
│ • 上次 WS 事件时间过久                      │
│ • 可能连接断开或网络问题                    │
│ → 降级到定时器，继续监听 WS 恢复            │
└─────────────────────────────────────────────┘
```

```

WebSocket 断开:

```
